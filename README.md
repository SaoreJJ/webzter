# Интернет-магазин Django

## Описание проекта
Этот проект представляет собой интернет-магазин, разрабатываемый в рамках учебного курса. Проект будет дорабатываться на протяжении всего курса.

## Технологии
- Python 3.11+
- Django 4.2+
- Bootstrap 5
- SQLite (на этапе разработки)
